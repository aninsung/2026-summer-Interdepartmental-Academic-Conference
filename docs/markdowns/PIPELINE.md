# 3D PPO Boundary Refiner 파이프라인 상세 문서

본 문서는 **Cost-Sensitive Reward 기반 3D PPO Boundary Refiner** 파이프라인의 전체 구조와 데이터 통제 메커니즘, 그리고 강화학습 에이전트의 훈련 과정을 상세히 다룹니다.

---

## 1. 한눈에 보는 파이프라인 구조

본 파이프라인은 정적인 딥러닝 초기 분할(Rough Mask)을 3D PPO 에이전트가 직접 탐색하며 다듬어 나가는 구조를 가집니다.

| 단계 (Stage) | 역할 및 동작 설명 | 주요 특징 |
|:---:|---|---|
| **Stage 1: Backbone** | **초기 로짓(Logit) 생성**: 3D U-Net 또는 SegResNet과 같은 딥러닝 백본 모델을 학습시켜 대략적인 초기 종양 분할 마스크를 생성합니다. | PPO 에이전트가 참고할 베이스라인 성능 확보 |
| **Stage 2: Cache** | **PPO 훈련 가속화**: 훈련 속도를 수십 배 끌어올리기 위해 PPO 훈련에 쓰일 환자들의 3D MRI 원본과 백본의 예측 로짓을 메모리에 미리 굽습니다(Cache). | 10초/환자 속도로 메모리 누수 완벽 차단 |
| **Stage 3: PPO** | **3D 경계 정밀 보정**: 에이전트가 15채널 관측값(MRI+Logits)을 바탕으로 초기 분할의 빈 곳을 메우고 잘못 튀어나온 가시를 깎아냅니다. | **10배 DSC 부스트 및 보상 클리핑** 적용 |
| **Stage 4: Evaluate** | **최종 성능 평가**: 에이전트의 학습 과정에 전혀 노출된 적 없는 Hold-out 환자들을 대상으로 최종 HD95 및 DSC 지표를 산출합니다. | 철저하게 통제된 `split.json`에 기반한 Data Leakage 제로 환경 |

## 2. PPO 에이전트 상세 구조 (Stage 3)

### 2.1 결정적 액션 스페이스 (Decisive Action Space)
기존의 RL 연구들은 픽셀 로짓값을 아주 미세하게(0.1~0.5씩) 조정하여 시간 낭비가 컸습니다. 
본 파이프라인의 에이전트는 확신을 가진 경계 픽셀에 대해 단 한 번의 액션(`logit_delta = 2.0`)으로 클래스를 완전히 역전시킬 수 있는 강력한 권한을 가지며, 에피소드당 최대 256번 타격을 허용합니다.

### 2.2 비대칭적 보상 설계 (Cost-Sensitive Reward)
의료 도메인에서는 엉뚱한 부피 팽창(False Positive)보다 **놓친 종양(False Negative)이 환자에게 훨씬 치명적**입니다.
이를 반영하여 다음과 같은 비대칭 구조의 보상을 설계했습니다:
1. **DSC Boost**: 에이전트가 놓친 종양을 메워 DSC가 0.01이라도 오르면 10배의 인센티브를 부여하되, 과도한 보상 해킹을 막기 위해 최대 보상을 50으로 클리핑합니다.
2. **HD95 Penalty**: 그러나 보상을 얻기 위해 엉뚱한 곳을 무작정 부풀리면, 종양 경계거리 오차(HD95)가 커지면서 수백 배의 페널티 폭탄을 맞습니다.
결과적으로 에이전트는 **'무지성 팽창은 포기하고 진짜 빈 공간(Hole)만 정밀 타격'**하는 완벽한 내쉬 균형(Nash Equilibrium) 상태에 도달합니다.

## 3. 완벽한 Patient-level Split 데이터 통제

BraTS 2021 대회 1,251명의 전체 데이터를 **환자 단위(Patient-level)**로 엄격하게 쪼개어 철저히 고립시켰습니다. 
(모든 분할 정보는 `runs/boundary_v5/split.json`에 안전하게 기록됩니다.)

| 역할 (Role) | 환자 수 | 할당 목적 |
|---|---:|---|
| **Backbone Train** | 656명 | 초기 분할 모델 가중치 훈련 (PPO 훈련에는 개입 불가) |
| **PPO (RL) Train** | 219명 | PPO 에이전트 훈련 전용 (백본 모델은 이 환자들의 라벨을 전혀 본 적 없음) |
| **Validation** | 188명 | 하이퍼파라미터 튜닝 및 모델 선택 |
| **Test (Hold-out)** | 188명 | 논문에 최종 보고될 성적 도출 (`TEST_RESULTS.md`) |

## 4. 정량적 검증 성과 (BraTS 2021 Hold-out 188명 기준)

최근 완료된 **V5 본학습 평가 결과**, 치명적 붕괴는 막았으나 에이전트가 학습을 포기하는 **정책 마비(Paralysis)** 상태에 빠졌음이 확인되었습니다.

| 세부 영역 | Backbone (초기) DSC | **Ours (V5 PPO)** DSC | HD95 감소 변화 |
|---|---:|---:|---:|
| **WT (Whole Tumor)** | 0.9310 | **0.9311** | 6.841 mm → **6.875 mm** (미세 악화) |
| **TC (Tumor Core)** | 0.9145 | **0.9145** | 5.767 mm → **5.762 mm** (기여 0) |
| **ET (Enhancing Tumor)** | 0.8581 | **0.8581** | 13.977 mm → **13.979 mm** (기여 0) |

*(차기 파이프라인 V6-A에서 상태 가치 $Q(s)$ 기반 보상 함수 및 결정적 검증 로직 도입을 통해 마비 현상을 타개할 예정입니다.)*
