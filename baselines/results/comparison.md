# BraTS 2021 상위 입상 방법 베이스라인 비교

베이스라인은 `checkpoints/patient_split.json`의 동일한 42명 검증 환자에서
동일한 지표 구현(`src/utils/metrics.py`)으로 측정했다.
3D/4모달리티/앙상블을 제외한 2D 각색 구현이므로 원 논문의 리더보드
점수와 직접 비교할 수 없다. 자세한 차이는 [baselines/README.md](../README.md) 참고.

- 베이스라인: 2026-08-19, seed 42, 이진화 임계값 0.5 (스윕 최적은 괄호), **2,373 슬라이스**
- 파이프라인: 2026-08-20, 임계값 0.80 / 0.80 / 0.50, **2,434 슬라이스** (같은 42명, 슬라이스 수는 다름)
- 비교 그림에서 Stage 3는 **TRIO**로 표기
