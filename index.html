02 / The question

왜 경계가 문제인가

하나의 모델이 모든 크기의 단면을 동시에 맞추면 위치는 맞아도 경계에서 과소분할이 남습니다.

Problem

Whole Tumor의 단면 크기는 슬라이스마다 달라집니다. 작은 단면과 큰 단면을 같은 방식으로 처리하면, 모델이 경계의 미세한 불확실성을 충분히 다루기 어렵습니다.

Design response

크기별 전문가가 먼저 확률 맵을 만들고, 하나의 경계 띠 PPO 정책이 0.35–0.65 확률 구간 또는 경계 ±2px만 선택적으로 보정합니다.

03 / Pipeline

분류하고, 분할하고, 보정한다

관측 단계에서 정답을 사용하지 않는 4단계 추론 파이프라인입니다.

01 / CLASSIFY

크기 분류

T1ce·FLAIR로 종양 면적을 Small / Medium / Large로 분류합니다.

02 / EXPERTS

전문가 선택

크기별 전문가가 확률 맵을 만들고 고정 임계값으로 이진화합니다.

03 / REFINE

경계 띠 PPO

애매한 경계 영역에서 켜기·유지·끄기 행동을 선택합니다.

04 / SCORE

환자 단위 평가

슬라이스 DSC를 환자마다 평균해 최종 성능을 비교합니다.
